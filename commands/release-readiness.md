# Command workflow: Release readiness

**Use when:** Trigger when user asks whether a release is ready or asks for a release checklist.

1. Assess deployment config, secret handling, migrations, compatibility, monitoring, rollback, smoke tests, runbooks, known issues and operational ownership as applicable.
2. Report readiness status and evidence-backed blockers/accepted risks.
3. Do not deploy/publish or change production settings unless separately authorized.
