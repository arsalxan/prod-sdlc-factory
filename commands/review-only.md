# Command workflow: Review only

**Use when:** Trigger when user asks for review/audit without asking for modifications.

1. Operate read-only.
2. Compare code with approved specs and relevant engineering/security standards.
3. Report findings by severity, confidence, evidence, affected requirement, expected/observed behavior, and suggested action.
4. Do not modify code or auto-invoke Bug Fixer. Wait for user authorization.
