# Command workflow: Authorized fix workflow

**Use when:** Trigger when user explicitly asks to fix a known issue or previously reported finding.

1. Resolve the exact authorized issue(s), inspect worktree, and reproduce where feasible.
2. Load relevant technology and testing skills.
3. Fix only authorized scope, add/update regression tests, avoid unrelated cleanup.
4. Run targeted and relevant regression checks; report evidence and residual risks.
5. If material requirements/architecture changes or destructive actions are needed, stop for approval.
