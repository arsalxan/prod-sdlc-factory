# Command workflow: Bug diagnosis

**Use when:** Trigger when user wants to understand a bug/test/CI failure before authorizing changes.

1. Reproduce or validate report from logs/tests/current code.
2. Identify likely root cause, affected requirements/components and evidence.
3. Keep investigation read-only unless the user clearly authorizes a fix.
4. Report confidence, remediation options, tests, and any needed authorization.
