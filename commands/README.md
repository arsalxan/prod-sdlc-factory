# Workflow command catalogue

These command specifications are portable internal workflows consumed by the controller. The controller routes requests automatically; the user does not need to type or select a command. GitHub Copilot prompt shortcuts live separately under `.github/prompts/`. A host-specific slash-command wrapper can be added later if a specific runtime requires one.

- `new-project.md`
- `feature-change.md`
- `bug-diagnosis.md`
- `authorized-fix.md`
- `review-only.md`
- `quality-gates.md`
- `github-workflow.md`
- `release-readiness.md`
- `resume.md`
