# Command workflow: Existing-project feature

**Use when:** Trigger for a new feature or enhancement in a repository that already exists.

1. Inspect repo instructions, worktree, stack, architecture and tests.
2. Map request to existing specs/contracts; raise a change to the approved spec if needed.
3. Plan a bounded change proportional to risk; stop for any required approval.
4. Load relevant skills; implement using TDD and preserve unrelated work.
5. Verify relevant integration/regression behavior, then report outcome and open findings.
