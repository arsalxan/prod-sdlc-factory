# React engineering skill

Inspect React version, framework (if any), language (TypeScript/JavaScript), router, state/data libraries, test tooling and project conventions. Keep components focused; derive state rather than duplicating it; use effects only to synchronize with external systems, not for ordinary derived calculations. Respect hook rules and stable keys. Avoid stale closures, unnecessary effects, uncontrolled async races and state mutation. Validate user input and handle loading/error/empty states. Preserve accessibility: semantic elements, labels, keyboard operation, focus handling, and appropriate roles. Avoid unsafe HTML injection and leaking secrets to client bundles. Test user-visible behavior, accessibility-relevant interactions and API integration; choose unit vs integration/E2E depth proportionately.
